# ICPC 区域赛银牌向训练题单



---

## 使用方法

建议不要单纯追求刷题数量。每道题补完后，至少记录下面四点：

1. 什么条件提示这个模型？
2. 最关键的状态、建图或转化是什么？
3. 为什么时间复杂度能通过？
4. 自己实现时最容易写挂在哪里？

推荐单题思考时间：

- 2100～2200：60～90 分钟
- 2300～2400：90～120 分钟
- 更高难度：可以作为拉伸题，超时后分层看题解

看题解时，优先只看第一层提示，不要直接复制完整代码。

# 第一阶段：优先完成

这一阶段的题目对 ICPC 区域赛银牌的迁移价值较高，建议优先完成。

## 图论与树

### 1. CF609E — Minimum spanning tree for each edge

- 链接：<https://codeforces.com/problemset/problem/609/E>
- 重点：最小生成树、LCA、树上路径最大边
- 核心训练：
  - 非树边加入生成树后，必须删除环上的最大边
  - 将 MST 与倍增维护路径信息结合
- 完成状态：`[ Accepted ]`
- 复习记录：比较简单 和之前洛谷上的 [Disruption P](https://www.luogu.com.cn/problem/P4374) 很像

---

### 2. CF160D — Edges in MST

- 链接：<https://codeforces.com/problemset/problem/160/D>
- 重点：Kruskal、按边权分组、并查集、割边
- 核心训练：
  - 判断边一定属于、可能属于或不属于 MST
  - 相同边权不能一条一条直接合并
  - 在缩点后的临时图中判断割边
- 完成状态：`[Accepted]`
- 复习记录：有点难, 没想到还和割边有关

---

### 3. CF208E — Blood Cousins

- 链接：<https://codeforces.com/problemset/problem/208/E>
- 重点：倍增祖先、DFS 序、按深度统计
- 核心训练：
  - 将树上子树查询转换为 DFS 序区间查询
  - 按深度维护结点的 DFS 序
- 完成状态：`[ Accepted ]`
- 复习记录：不怎么难想, 下次可以记得从dfn序列入手树的题目

---

### 4. CF587C — Duff in the Army

- 链接：<https://codeforces.com/problemset/problem/587/C>

- 核心训练：

# 组队 VP 建议

目标是 ICPC 区域赛银牌，因此不能只做单题，也要练习完整的五小时赛制。

推荐平台：

- QOJ
- UCup
- ICPC 区域赛重现赛
- Codeforces Gym

你在队伍中的建议定位：

```text
图论 / 树
数据结构
动态规划
字符串
复杂实现与调试
```

开场读题时优先关注：

- 树、图、路径、连通性
- 区间修改与查询
- 离线操作
- \(n\le 20\) 左右的状态压缩
- 多模式字符串匹配
- 能转成最短路或网络流的问题

# 每周训练安排

一个较稳定的安排：

| 训练内容 | 数量 |
|---|---:|
| 第一阶段核心题 | 2 道 |
| 第二阶段突破题 | 1 道 |
| Codeforces / AtCoder 正赛或补题 | 1 场 |
| 五小时组队 VP | 每 7～10 天 1 场 |

不要在一周内塞太多高难题。重点是将做过的题真正转化成比赛能力。

# 当前阶段不建议投入过多时间的内容

- 裸模板题
- 极特殊的高难构造
- 只在一道题里成立的复杂状态压缩
- 纯粹码量巨大但没有新思想的数据结构题
- 与队友职责重叠的纯数学方向

当前更推荐的题目特征是：

> 一个熟悉算法，加一个需要自己发现的转化。

而不是：

> 多个冷门技巧堆在一起，做完后很难迁移。
