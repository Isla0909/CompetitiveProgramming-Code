# 1. 训练等级

### S｜主线
区域赛主力应尽量稳定拿下。
一般不需要学习大型新框架，重点是模型识别、转化和实现。

### A｜强化
通常比 S 多一个关键观察，或者需要两层模型组合。
这是你当前最应该大量训练的一档。

### X｜金牌分界冲刺
不是神仙题，不是“全场几个人过”的题。
但属于银牌上沿选手冲击金牌时很值得啃的题。

# 2. 第一阶段：性质 → DP 转移

## 1. CF264C - Choosing Balls
- 链接：https://codeforces.com/problemset/problem/264/C
- 等级：S
- 核心：DP、按颜色维护最优、最大值 / 次大值
- 训练价值：
  - “不能从同类最优转移” → 维护 top1 + top2。
  - 很经典的**排除一个类别**技巧。
- 重点：别枚举所有颜色。

## 2. CF543A - Writing Code
- 链接：https://codeforces.com/problemset/problem/543/A
- 等级：S
- 核心：二维背包式 DP
- 训练价值：
  - 把“写多少行 + 产生多少 bug”压进状态。
  - 练 DP 状态定义稳定性。
- 定位：故意简单一点，用来提高一次通过率。

## 3. CF577B - Modulo Sum
- 链接：https://codeforces.com/problemset/problem/577/B
- 等级：S
- 核心：鸽巢原理 + 余数 DP
- 训练价值：
  - 先用性质砍掉大数据，再 DP。
  - 非常典型的“先证明，再写算法”。

## 4. CF580D - Kefa and Dishes
- 链接：https://codeforces.com/problemset/problem/580/D
- 等级：S
- 核心：状压 DP、最后一个元素
- 训练价值：
  - 当前收益依赖“上一个选择” → 把历史压进状态。
- 对应复习：
  - CF59E / CF1486E 的“少量历史信息进状态”。

## 5. CF629C - Famil Door and Brackets
- 链接：https://codeforces.com/problemset/problem/629/C
- 等级：S
- 核心：括号 balance DP
- 训练价值：
  - 合法括号串 = 前缀 balance 非负 + 最终回零。
  - 和西安邀请赛 C 的 balance 分析形成复习组。

## 6. CF711C - Coloring Trees
- 链接：https://codeforces.com/problemset/problem/711/C
- 等级：S/A
- 核心：DP、段数、上一个颜色
- 训练价值：
  - “形成多少个连续块”是常见附加维度。
  - 练三维状态如何压清楚。

## 7. CF1132F - Clear the String
- 链接：https://codeforces.com/problemset/problem/1132/F
- 等级：A
- 核心：区间 DP、相同字符合并
- 训练价值：
  - **CF607B Zuma 的直接复习题。**
  - 固定左端点，考虑它最后和哪个相同字符一起处理。
- 必做理由：
  - 你刚刚正好在练“删除中间后，两端合并”。

## 8. CF1154F - Shovels Shop
- 链接：https://codeforces.com/problemset/problem/1154/F
- 等级：S
- 核心：排序 + DP、优惠结构
- 训练价值：
  - 先证明只取最便宜的一批，再 DP。
  - 练“贪心性质给 DP 降维”。

## 9. CF1209E2 - Rotate Columns
- 链接：https://codeforces.com/problemset/problem/1209/E2
- 等级：A
- 核心：挑关键列 + 状压 DP
- 训练价值：
  - 大矩阵先证明真正有用的列很少。
  - 再在小空间做暴力 / DP。
- 重点：
  - **性质 → 降维 → 状压**。

## 10. CF1433F - Zero Remainder Array
- 链接：https://codeforces.com/problemset/problem/1433/F
- 等级：A
- 核心：分层背包、模意义状态
- 训练价值：
  - 先做每一行的局部 DP，再合并全局。
  - 区域赛常见“局部限制 + 全局目标”。

## 11. CF1557D - Ezzat and Grid
- 链接：https://codeforces.com/problemset/problem/1557/D
- 等级：A
- 核心：DP + 线段树、区间贡献
- 训练价值：
  - 把二维连接条件转成可维护的区间最优。
  - 很符合“先看转移瓶颈，再设计数据结构”。

## 12. CF1856E1 - PermuTree (easy version)
- 链接：https://codeforces.com/problemset/problem/1856/E1
- 等级：A
- 核心：树形 DP + 子树大小背包
- 训练价值：
  - 从树结构性质推出局部 partition DP。
  - 很适合练“性质 → 转移”。

- **A：独立做出**
- **B：有方向，差最后一刀**
- **C：需要关键提示**
- **D：需要完整题解**

```text
最近 8 题：
A：
B：
C：
D：

重复出现的卡点：
1.
2.

实现错误：
1.
2.

本阶段最值得复习的 2 题：
1.
2.

下一阶段：
```

如果 B 类特别多：

> 不加难度，继续做同档相似题。

# 12. 这版最重要的训练规则

## 规则 1：想出性质后，不许停在“然后呢”

强制问三个问题：

```text
这个性质能不能：
1. 减少状态？
2. 减少枚举？
3. 把多个步骤打包成一次转移？
```

西安邀请赛 C：

```text
每两层必须一正一负
↓
两层绑定
↓
打包成一次选四个字符
```

就是标准例子。

---

## 规则 2：看到 O(n²) / O(n³) 暴力后先别扔

问：

```text
哪一维其实可以：
- 排序固定
- 单调
- 只保留最优代表
- 用前后缀
- 用数据结构批量维护
```

---

## 规则 3：正确算法出来后，再做一次“降维”

近期典型：

```text
ABC235E：
MST + LCA 能做
↓
实际上只要按权离线 + DSU
```

比赛里正确大炮能过就先写；
训练时 AC 后再问有没有更本质做法。

---

## 规则 4：实现错误单独训练

近期常见：

- 树读成 n 条边而不是 n-1；
- 修改错数组名；
- 状态 `(pre,u)` 顺序写反；
- 区间 DP 漏空区间；
- `?:` 优先级；
- 边界为了防越界把合法转移一起删掉。

这些不是“粗心”两个字就结束。

每出现一次都应该写入 Debug 清单。

---

# 13. 最终目标

不是做到：

> “我能看懂 2400 的题解。”

而是做到：

> **区域赛前中段题稳定收，银牌上沿题高概率做出，金牌分界题经常能自己走到最后一刀，并且有能力把那一刀补完。**

这才是最后一个赛季最值得追的提升。
