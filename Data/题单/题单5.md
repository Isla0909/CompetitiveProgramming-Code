# ICPC 最后赛季弱点专项训练题单 v5

> 目标：**稳定区域赛银牌，不再让“看懂过程但压不出性质”成为中后段题的主要失分点。**
>
> 这一版不是算法大全，也不是把难度继续往上堆。
>
> 它是基于整个「ICPC 区域赛银牌训练」项目里近期反复暴露的问题，专门做的一轮 **弱点矫正题单**。

---

# 0. 这版为什么重新做

前几版已经覆盖了大量常规银牌模型：树上差分、LCA、换根、SCC、最短路状态扩展、线段树、莫队、KMP/Z、区间 DP、分治优化等。

近期真正反复卡住的，不再主要是“没学过某个算法”，而是下面这些更底层的能力：

## 短板 A：会模拟过程，但不会主动把过程压成性质

近期典型：

- QOJ Coin：
  - 会写一轮人数变化；
  - 会理解逆推位置；
  - 但一开始没有主动问：`ceil(n/k)` 会连续多少轮不变？
- CF2258 B2 Carrot Chopdown：
  - 能看到 `log m`；
  - 但没有立刻把“单根贡献”写成阈值计数，再做整体贡献。
- 四川省赛 E：
  - 能感觉到“祖先翻过以后下面变自由”；
  - 但容易继续纠结翻 / 不翻，而没有把自由状态直接塌缩成公式。

### 本轮要形成的条件反射

看到很长的操作过程，强制问：

1. 真正变化的量是什么？
2. 哪个商 / 阈值 / 状态会在一段时间内保持不变？
3. 能不能一次跳很多步？
4. 能不能倒着做？
5. 某个状态出现后，后续是否已经完全自由？

---

## 短板 B：单个对象会算，但不会把贡献改写成可批量统计的形式

近期典型：

- B2：
  - 单根胡萝卜的贡献可以理解；
  - 但关键是把 `min(floor(a/x), K)` 转成若干个 `[a >= jx]`。
- 多道树 / 区间题里也反复出现：
  - 先逐对象分析；
  - 再通过前缀、后缀、差分、Fenwick、DSU 批量统计。

### 本轮要形成的条件反射

看到：

- `min(q, C)`
- “第几个开始贡献”
- “某段时间一直有效”
- “所有满足阈值的对象都 +1”

先想：

- 阈值拆分；
- 差分；
- 前后缀；
- 离线排序；
- DSU 合并贡献。

---

## 短板 C：贪心直觉经常是对的，但缺乏“分支为什么只有这些”的证明

近期典型：

- 四川省赛 L：
  - 已经想到“短不一定字典序更小”；
  - 但 `s[l] == s[r]` 时最开始只看相邻字符；
  - 实际要压缩整段相同字符，看第一个不同字符。
- 四川省赛 F：
  - 尝试维护两个 gcd 组；
  - 局部“现在能塞进去”并不能推出“应该塞进去”。

### 本轮要形成的条件反射

贪心前先问：

1. 第一次产生不同答案的位置在哪里？
2. 决策只取决于哪几个边界量？
3. 当前局部选择能否用交换论证证明？
4. 如果没有证明，不要因为“样例都对”就继续补丁。

---

## 短板 D：大状态空间里，不够主动寻找“真正需要枚举的少量候选”

近期典型：

- 四川省赛 F：
  - 整体 gcd 归一化；
  - 两个质因子覆盖；
  - 最后只需要从少数元素的质因子里枚举候选。
- 西安邀请赛 C：
  - 观察到结构以后，还需要继续问能否打包层 / 减少枚举。
- 多个图 / DP：
  - 历史看起来很长；
  - 实际未来只依赖最后一个颜色、上一条边、少量关键事件。

### 本轮要形成的条件反射

看到巨大候选空间时，强制问：

- 是否至少有一个最优候选来自某个“小集合”？
- 是否能取代表点 / 端点 / 最大次大？
- 是否能把等价状态合并？
- 是否只有特殊事件需要进入 DP？

---

## 短板 E：实现阶段的控制流与边界仍然会浪费已经正确的思路

近期典型：

- 四川省赛 L：
  - `if (l <= r + 1)` 永远成立；
  - 少 `continue` 后，同一轮移动两次指针。
- B2：
  - 特殊项更新放进了 `j` 循环；
  - 同一个 `cnt[len*x]` 被重复减。
- 线段树 / FHQ / 动态结构：
  - 算法方向正确后，边界、pushup、下标经常成为最后 WA 原因。

### 本轮训练要求

每题 AC 前必须做一次：

```text
1. 这个变量的语义是什么？
2. 这个循环每一层到底更新几次？
3. 这个 if 的逻辑条件是否可能恒真 / 恒假？
4. 1-index / 0-index 是否混了？
5. 边界状态是否真的允许继续操作？
```

# 1. 难度标记

## S｜核心题

银牌主力应尽量稳定掌握。

特点：

- 常见；
- 可迁移；
- 不依赖很怪的新知识；
- 重点是性质识别和实现稳定。

## A｜强化题

比核心题多一刀转化，或者需要两层经典模型组合。

**这是本轮最重要的一档。**

## X｜挑战题

银牌上沿 / 金牌分界附近的高价值题。

不是要求赛场稳定秒出，而是学习：

- 如何继续压状态；
- 如何发现根号 / 单调 / 隐式图；
- 如何把已经正确的暴力优化掉。

> 本轮没有安排“全场极少队通过”的异常难题。

## 1. CF1179A - Valeriy and Deque

- 链接：https://codeforces.com/problemset/problem/1179/A
- 等级：S｜专项热身
- 核心：过程模拟、稳定状态、周期
- 现场触发器：查询第 `10^18` 次操作；系统运行一段时间后结构会稳定并进入循环。
- 训练价值：先模拟到最大值到达队首；后面不再模拟，而是周期取模。
- 对应短板：**过程很长 → 先找进入稳定状态的时刻。**
- 建议时限：20 分钟。

## 2. CF1705C - Mark and His Unfinished Essay

- 链接：https://codeforces.com/problemset/problem/1705/C
- 等级：S
- 核心：逆向映射、区间复制
- 现场触发器：正向构造出的字符串可能极长；只询问最终某个位置的字符。
- 训练价值：不构造结果；把最终位置一层层映射回原串位置。
- 对应短板：**正向过程巨大 → 逆着追一个查询。**
- 强烈推荐。

## 3. CF1601B - Frog Traveler

- 链接：https://codeforces.com/problemset/problem/1601/B
- 等级：A
- 核心：BFS、区间可达、删除已处理状态
- 现场触发器：一个状态能一次转移到一整段位置；暴力枚举区间会 `O(n^2)`。
- 训练价值：一个位置只需要被真正扫描一次；用 set / next 指针把“重复枚举区间”消掉。
- 对应短板：**很多轮 / 很多区间重复处理 → 让每个状态只被处理一次。**

## 4. AtCoder ABC346 E - Paint

- 链接：https://atcoder.jp/contests/abc346/tasks/abc346_e
- 等级：S
- 核心：操作倒序、最后一次覆盖、计数
- 现场触发器：行 / 列不断被覆盖；正向维护每个格子明显不可能。
- 训练价值：倒着看时，第一次遇到某行 / 列就是它最后一次生效。
- 对应短板：**覆盖操作 → 倒序后只看第一次。**

## 5. AtCoder ABC347 E - Set Add Query

- 链接：https://atcoder.jp/contests/abc347/tasks/abc347_e
- 等级：A
- 核心：时间贡献、前缀和、元素活跃区间
- 现场触发器：每次集合大小会同时影响所有当前在集合中的元素。
- 训练价值：不逐次给集合所有元素加；把一个元素在集合中的时间段转成前缀和差。
- 对应短板：**操作过程 → 活跃区间 → 一次结算贡献。**

# 4. 必做第三组：不变量 / 全局性质 → 缩小候选

对应四川 F、西安邀请赛 C 一类题。

## 11. CF1632D - New Year Concert

- 链接：https://codeforces.com/problemset/problem/1632/D
- 等级：A
- 核心：GCD、不变量、区间判断、贪心截断
- 现场触发器：条件是 `gcd(segment) == length(segment)`；gcd 随区间扩张单调不增。
- 训练价值：不要枚举所有左端点；利用 gcd 的结构快速判断“这一段是否第一次触发坏状态”。
- 对应短板：**先研究一个区间量随扩张如何变化。**

## 12. CF1307D - Cow and Fields

- 链接：https://codeforces.com/problemset/problem/1307/D
- 等级：A
- 核心：两次 BFS、排序、候选对降维
- 现场触发器：看似要枚举 `O(k^2)` 对特殊点。
- 训练价值：每个点只保留与 `dist1`、`distN` 有关的两个量；排序后维护最优代表。
- 对应短板：**两两枚举 → 找排序关键字 → 只保留历史最优。**

## 13. CF1398E - Two Types of Spells

- 链接：https://codeforces.com/problemset/problem/1398/E
- 等级：A
- 核心：multiset、不变量、动态维护 top-k
- 现场触发器：每次插入 / 删除；最优答案看起来需要重新排序全部元素。
- 训练价值：明确“应该被翻倍的元素数量”；动态维护这一批最大的值；再处理一个特殊边界。
- 对应短板：**全局最优排列 → 抓住真正影响答案的那一段 top-k。**

## 14. CF1623C - Balanced Stone Heaps

- 链接：https://codeforces.com/problemset/problem/1623/C
- 等级：S/A
- 核心：二分答案、逆序贪心、资源传播
- 现场触发器：问最大化最小值；操作只能从后往前输送资源。
- 训练价值：check 时必须按操作方向逆序；区分“原本拥有的资源”和“后来收到的资源”能否再次转移。
- 对应短板：**先定目标，再只做必要的资源转移。**

## 19. CF1295E - Permutation Separation

- 链接：https://codeforces.com/problemset/problem/1295/E
- 等级：A
- 核心：枚举值域分界、线段树维护所有位置分界代价
- 现场触发器：同时有“按位置切一刀”和“按值切一刀”两维。
- 训练价值：一维按值从小到大扫描；另一维所有切点的代价用线段树整体更新。

## 20. CF1555E - Boring Segments

- 链接：https://codeforces.com/problemset/problem/1555/E
- 等级：A
- 核心：排序、双指针、区间覆盖、线段树维护最小覆盖次数
- 现场触发器：目标是 `max(w)-min(w)`；通常暗示按 `w` 排序后滑窗。
- 训练价值：窗口是否合法 = 所有相邻点都至少被一个区间覆盖；线段树只维护全局最小覆盖次数。
- 对应短板：**复杂可行性条件 → 找一个可 merge 的全局最小量。**

## 21. CF1788E - Sum Over Zero

- 链接：https://codeforces.com/problemset/problem/1788/E
- 等级：A
- 核心：前缀和 DP、离散化、数据结构优化转移
- 训练价值：先写出 `O(n^2)`：最后一个合法非负和区间从哪里开始？再把 `pre[j] <= pre[i]` 这类条件转成值域查询。
- 对应短板：**先保留正确 DP，再优化“从哪些 j 转移”。**

## 22. CF1913D - Array Collapse

- 链接：https://codeforces.com/problemset/problem/1913/D
- 等级：A/X
- 核心：DP、单调栈、结构压缩
- 训练价值：操作过程看起来有大量不同删除顺序；真正决定可达结构的是区间最小值关系。
- 对应短板：**过程题 → 找决定结构的代表元素 → 单调栈压状态。**
- 定位：本轮最难的 DP 主线之一；卡 60～75 分钟可以看关键观察，不建议死磕半天。

## 30. CF1430E - String Reversal

# 12. 本轮特殊训练规则

## 规则 1：禁止“想到一个性质以后就停”

每次想到性质以后，继续强制问：

```text
然后呢？

它能不能：
1. 直接算一整段？
2. 合并一批状态？
3. 只枚举少数代表？
4. 倒着做？
5. 变成贡献？
```

## 规则 2：遇到巨大操作次数，先找“什么时候转移不变”

尤其看到：

```text
floor(...)
ceil(...)
除法
阈值
每轮减去某个函数值
```

先尝试：

```text
令 d = 当前商 / 当前步长
反解 d 保持不变的区间
一次跳到边界
```

QOJ Coin 就是本轮的标杆复习题。

## 规则 3：遇到逐对象贡献，先尝试阈值拆分

例如：

```text
min(q, C)
```

不要只会直接算每一个对象。

尝试：

```text
[q >= 1] + [q >= 2] + ... + [q >= C]
```

然后看看能否变成：后缀计数、差分、Fenwick、离线扫描。

B2 就是本轮的标杆复习题。

## 规则 4：贪心必须回答“为什么另一种选择永远不更好”

禁止：

> “我模拟很多样例感觉是对的。”

必须至少有一个：交换论证、第一次不同位置、单调性、边际代价、“越早做越不亏”、最优解标准化。

## 规则 5：代码写完后检查循环语义

尤其检查：

```text
这个更新应该：
- 每个元素一次？
- 每个块一次？
- 每个 j 一次？
- 每个测试一次？
```

B2 的特殊项重复更新就是典型。

# 14. 这一版真正的验收目标

做完以后，不要求“学会 30 个新算法”。

希望形成下面这些比赛反射：

```text
过程特别长
→ 能不能逆推 / 找周期 / 批量跳？

逐个对象很好算
→ 能不能改写成贡献 / 阈值？

两两枚举
→ 能不能排序以后只留一个最优代表？

状态很多
→ 哪些其实等价？哪些一旦出现就彻底自由？

贪心感觉很对
→ 第一次产生字典序差异的位置在哪？
→ 能否交换证明？

O(n^2) 转移已经正确
→ 哪个条件可以离线 / 单调 / 数据结构维护？

隐式边太多
→ 有没有共同标签 / 中间状态可以压图？
```

如果这几条形成条件反射，提升会比单纯再刷一批“会模板就能过”的 2000 分题明显得多。
