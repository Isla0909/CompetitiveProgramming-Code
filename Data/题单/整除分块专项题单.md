# 整除分块专项题单

> 目标：把整除分块从“会写板子”练到“看到题目能主动把式子转成 `floor(n / i)` 的形式”。
>
> 建议顺序：**必做 → 强化 → 挑战**。  
> 重点训练：整除分块、带权求和、多个 floor 同时分块、约数贡献转换、mod 拆式。

---

## 0. 核心板子

对于固定的 `n`，当

\[
q=\left\lfloor\frac{n}{l}\right\rfloor
\]

时，最大的右端点为

\[
r=\left\lfloor\frac{n}{q}\right\rfloor.
\]

代码：

```cpp
for (i64 l = 1, r; l <= n; l = r + 1)
{
    i64 q = n / l;
    r = n / q;

    // [l, r] 中 n / i 都等于 q
}
```

复杂度：

\[
O(\sqrt n)
\]

## 1. 必做：ABC230 E - Fraction Floor Sum

- 来源：AtCoder
- 链接：https://atcoder.jp/contests/abc230/tasks/abc230_e
- 难度：核心入门
- 主要算法：整除分块
- 训练价值：★★★★★

### 题目核心

求：

\[
\sum_{i=1}^{N}\left\lfloor\frac Ni\right\rfloor
\]

### 训练目标

做到看到题目后能立刻写出：

```cpp
for (i64 l = 1, r; l <= n; l = r + 1)
{
    i64 q = n / l;
    r = n / q;

    ans += q * (r - l + 1);
}
```

### 为什么推荐

这是最纯的整除分块板子题。

建议以后把

\[
r=\frac{n}{n/l}
\]

练成条件反射。

## 2. 必做：P3935 Calculating

- 来源：洛谷
- 链接：https://www.luogu.com.cn/problem/P3935
- 难度：核心
- 主要算法：约数贡献转换 + 整除分块
- 训练价值：★★★★★

### 关键转换

设 \(d(x)\) 表示 \(x\) 的约数个数。

需要理解：

\[
\sum_{x=1}^{n} d(x)
=
\sum_{i=1}^{n}\left\lfloor\frac ni\right\rfloor
\]

### 为什么？

换枚举顺序。

固定一个约数 \(i\)，在 \(1\sim n\) 中：

\[
i,2i,3i,\ldots
\]

共有：

\[
\left\lfloor\frac ni\right\rfloor
\]

个数含有约数 \(i\)。

所以：

\[
\boxed{
\text{枚举每个数的约数}
\Longleftrightarrow
\text{枚举每个约数的倍数}
}
\]

### 更通用的式子

\[
\boxed{
\sum_{x=1}^{n}\sum_{d\mid x}g(d)
=
\sum_{d=1}^{n}
g(d)\left\lfloor\frac nd\right\rfloor
}
\]

这是非常重要的竞赛转换。

## 3. 必做：P2261 [CQOI2007] 余数求和

- 来源：洛谷
- 链接：https://www.luogu.com.cn/problem/P2261
- 难度：核心
- 主要算法：mod 拆式 + 带权整除分块
- 训练价值：★★★★★

### 关键转换

\[
k\bmod i
=
k-i\left\lfloor\frac ki\right\rfloor
\]

所以：

\[
\sum_{i=1}^{n}k\bmod i
=
nk-\sum_{i=1}^{n}i\left\lfloor\frac ki\right\rfloor
\]

在一个整除块 \([l,r]\) 中：

\[
\left\lfloor\frac ki\right\rfloor=q
\]

于是这一块贡献：

\[
q\sum_{i=l}^{r}i
\]

而：

\[
\sum_{i=l}^{r}i
=
\frac{(l+r)(r-l+1)}{2}
\]

### 训练目标

学会看到：

- `%`
- `mod`
- 余数

第一反应尝试：

\[
a\bmod b=a-b\left\lfloor\frac ab\right\rfloor
\]

---

## 4. 必做：P2424 约数和

- 来源：洛谷
- 链接：https://www.luogu.com.cn/problem/P2424
- 难度：核心
- 主要算法：约数贡献 + 带权整除分块
- 训练价值：★★★★★

### 关键转换

定义：

\[
\sigma(x)=\sum_{d\mid x}d
\]

那么：

\[
\sum_{x=1}^{n}\sigma(x)
=
\sum_{d=1}^{n}
d\left\lfloor\frac nd\right\rfloor
\]

和 P3935 的区别：

P3935：

\[
g(d)=1
\]

P2424：

\[
g(d)=d
\]

### 训练重点

把：

\[
\sum_{d=l}^{r}d
\]

和整除分块结合起来。

## 5. 复习题：QOJ 8758 Menji 和 gcd

- 来源：QOJ
- 链接：https://qoj.ac/contest/1692/problem/8758
- 难度：核心偏提升
- 主要算法：GCD 转倍数计数 + 多个 floor 同时整除分块
- 训练价值：★★★★★

### 核心判定

对于候选 \(x\)，区间 \([L,R]\) 中 \(x\) 的倍数个数为：

\[
\left\lfloor\frac Rx\right\rfloor
-
\left\lfloor\frac{L-1}{x}\right\rfloor
\]

如果至少有两个：

\[
\left\lfloor\frac Rx\right\rfloor
-
\left\lfloor\frac{L-1}{x}\right\rfloor
\ge 2
\]

则答案至少可以达到 \(x\)。

### 多个 floor 同时分块

对于当前左端点 `l`：

```cpp
q1 = R / l;
q2 = (L - 1) / l;
```

分别计算两个 floor 保持不变的最右端：

```cpp
r1 = R / q1;
r2 = (L - 1) / q2;
```

共同的右端：

```cpp
r = min(r1, r2);
```

### 注意

如果：

```cpp
q2 == 0
```

不能计算：

```cpp
(L - 1) / q2
```

需要单独处理。

### 复习建议

3～5 天后重新裸写一次。

# 必须形成的四个条件反射

## 1. 商

\[
q=\left\lfloor\frac nl\right\rfloor
\]

## 2. 最右端

\[
r=\left\lfloor\frac nq\right\rfloor
\]

也就是：

```cpp
r = n / (n / l);
```

---

## 3. 多个 floor

如果同时出现：

\[
\left\lfloor\frac{A}{i}\right\rfloor,
\qquad
\left\lfloor\frac{B}{i}\right\rfloor
\]

就分别算块右端：

\[
r_1=\frac{A}{A/l},
\qquad
r_2=\frac{B}{B/l}
\]

然后：

\[
\boxed{r=\min(r_1,r_2)}
\]

---

## 4. mod 拆式

看到：

\[
a\bmod b
\]

考虑：

\[
\boxed{
a\bmod b
=
a-b\left\lfloor\frac ab\right\rfloor
}
\]
