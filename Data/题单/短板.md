# 1. 这版真正针对什么

结合整个项目近期训练，你现在最需要补的不是“再学 10 个算法名字”，而是下面这些比赛能力：

1. **过程 → 性质 / 逆推 / 批量跳转**：会理解模拟，但不够主动问“什么时候一整段行为都一样”。
2. **单点贡献 → 整体统计**：单个对象会算，但不够主动改写成阈值、差分、前后缀、离线贡献。
3. **贪心证明与完整分类**：直觉经常对，但容易停在“样例感觉很对”。
4. **缩候选 / 合并等价状态**：大状态空间中，不够主动找代表点、质因子、SCC、最后事件、边界状态。
5. **正确暴力 → 最后一刀优化**：DP/搜索已经正确后，数据结构、根号分治、离线化这一步不够稳定。
6. **实现稳定性**：循环层级、恒真条件、少 `continue`、off-by-one、终止边界会浪费已经正确的思路。

近期标杆复习题：四川省赛 E/F/L、CF2258 B2、QOJ 9864 Coin。

# 2. 难度标记

- **S｜核心题**：区域赛银牌主力应尽量稳定掌握。
- **A｜强化题**：比舒适区高一档，通常需要两层性质或“暴力 → 优化”完整链条。
- **X｜挑战题**：银牌上沿 / 金牌分界附近，可以看关键提示，不要求正赛稳定秒出。
- **G｜金牌学习题**：明确不是当前稳定银牌必须独立做出的题。

- **来源**：2023 广东省赛 / Universal Cup

# 8. 近期回炉区（不计入新题）

## R1. 四川省赛 F

```text
左右 gcd 相等
→ 只能等于整体 gcd
→ 除掉整体 gcd
→ 两个质因子覆盖，允许漏一个
→ 候选只从少数元素的质因子中枚举
```

验收：能自己 hack “两个 gcd 组贪心”；能重新推出为什么只需看少数元素的质因子。

## R2. 四川省赛 E

```text
正向操作难数
→ 倒着看
→ 祖先一旦翻过
→ 下面获得自由
→ 自由状态直接塌成 2^size
```

验收：不再维护“到底翻了几次”；主动发现“自由状态无需继续 DP”。

## R3. 四川省赛 L

```text
两端不同 → 直接取小
两端相同 c
→ 不能只看相邻字符
→ 跳过左右连续 c 段
→ 看第一个不同字符
→ 决定希望 c 多出现还是少出现
```

必须能解释 `aabaa` 为什么 hack 掉“相等就双删”。

## R4. CF2258 B2 - Carrot Chopdown

```text
固定 k
→ 固定目标长度 x
→ 单根贡献
→ min(floor(a/x), K-1) + [a=Kx]
→ min 拆成阈值计数
→ suf[j*x]
→ K 翻倍时增量维护
```

验收：不看题解重新推出 `val[x]`；知道特殊项为什么每层只更新一次。

## R5. QOJ 9864 - Coin

- **来源**：2024 ICPC 昆明区域赛
- **QOJ**：https://qoj.ac/problem/9864

```text
人数正推：n -= ceil(n/k)
赢家逆推：x += ceil(x/(k-1))
轮数巨大
→ ceil 的值连续多轮不变
→ 反解区间
→ 一次跳 t 轮
```

必须能重新推出：

```text
L = (d - 1) * k + 1
R = d * (k - 1)
```

并记得：分块区间允许继续，不等于题目过程允许继续；人数不能跨过 1。

# 11. 本版特殊训练规则

## 规则 1：想到一个性质以后禁止停在“然后呢”

继续强制问：

```text
它能不能直接算一整段？
能不能合并一批状态？
能不能只枚举少数代表？
能不能倒着做？
能不能变成贡献？
```

## 规则 2：出现 floor / ceil / 整除 + 巨大过程，先想商分块

```text
令 d = 当前商
反解 d 保持不变的区间
计算还能走几轮
一次跳到边界
```

QOJ Coin 是这一条的标杆复习题。

## 规则 3：单点贡献会算以后，尝试阈值拆分

例如：

```text
min(q, C)
= [q>=1] + [q>=2] + ... + [q>=C]
```

再看能否变成后缀、差分、Fenwick、离线扫描。

## 规则 4：贪心必须回答“为什么另一种选择不会更好”

至少要有交换论证、第一次不同位置、单调性、边际代价之一。

## 规则 5：代码写完检查循环语义

```text
这个更新应该每个元素一次？
每个块一次？
每个 j 一次？
每个测试一次？
这个 if 会不会恒真？
这个状态到终点以后还能不能继续？
```

# 12. 最终目标

做完这版，不要求多会 20 个偏门算法。

真正希望形成这些比赛反射：

```text
操作次数巨大
→ 稳定值 / 商分块 / 周期 / 逆推

单个对象会算
→ 贡献 / 阈值 / 差分 / 离线

图状态太多
→ SCC / 拆点 / 势能 / 等价类

候选太多
→ 少量代表 / 质因子 / 端点 / 最后事件

贪心感觉很对
→ 第一次不同位置 / 交换证明

DP 已经 O(n^2)
→ 哪个转移条件能批量维护？

思路已经对
→ 再检查循环层级、边界和变量语义
```

如果这些形成条件反射，比继续刷一批普通 CF 1900 更接近“稳定区域赛银牌”。
